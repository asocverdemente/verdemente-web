VERDEMENTE · PACK WEB SABERES DEL TERRITORIO · V2

QUÉ INCLUYE
- index.html: portada actualizada, sin la sección Memoria.
- saberes-del-territorio.html: página general con los 7 saberes enlazados.
- 7 páginas individuales de saberes.
- inscripcion-campanas.html e inscripcion-alfareria.html.
- jornadas-arte-patrimonio-dehesa.html: página independiente de las Jornadas.
- assets/img/: imágenes tomadas de las portadas que ya habíamos creado, recortadas para evitar textos/fechas antiguas y pies con logos generados.
- assets/logo-verdemente.png: logo real de VerdeMente.
- styles.css y script.js.
- google-apps-script.gs: guarda las inscripciones en una hoja de Google Sheets, una persona por fila.
- form-config.js: aquí se pega UNA SOLA VEZ la URL del Apps Script y sirve para los dos formularios.

CÓMO SUBIR
1. Descomprime el ZIP.
2. En GitHub > asocverdemente/verdemente-web > Add file > Upload files.
3. Arrastra TODOS los archivos y carpetas de este pack a la raíz del repositorio.
4. Confirma la sustitución de los archivos con el mismo nombre y pulsa Commit changes.
5. Espera 1–2 minutos a GitHub Pages.

CONECTAR LOS FORMULARIOS A UNA TABLA
1. Crea una Hoja de cálculo de Google vacía.
2. Extensiones > Apps Script.
3. Sustituye el contenido por google-apps-script.gs.
4. Implementar > Nueva implementación > Aplicación web.
5. Ejecutar como: tú. Acceso: cualquier usuario.
6. Copia la URL terminada en /exec.
7. Abre form-config.js y pega esa URL entre las comillas:
   window.VERDEMENTE_FORM_ENDPOINT = 'https://script.google.com/.../exec';
8. Sube solo form-config.js de nuevo a GitHub.

La hoja creará una pestaña llamada “Inscripciones”. Se puede ordenar/filtrar y descargar con Archivo > Descargar > Microsoft Excel (.xlsx).

EVENTOS UEX
Las páginas de Campanas y Alfarería incluyen un acceso a Eventos UEx. Cuando tengas la URL específica de cada evento, sustituye el enlace general https://eventos.unex.es/ por la ficha concreta.

LOGOS
- VerdeMente: archivo local original.
- UEx: se carga desde el recurso oficial de la Universidad para evitar reconstruirlo.
- Junta: se representa mediante el código de bandera verde-blanco-negro y la denominación institucional, junto a la frase exigida “Proyecto subvencionado por la Junta de Extremadura”. Si descargas el logotipo oficial que te facilite la Junta, lo podemos sustituir por ese archivo local sin tocar el diseño.
